ВИКОРИСТАННЯ ШІ ПІД ЧАС РОЗРОБКИ
Під час виконання лабораторної роботи було використано інструмент штучного інтелекту Claude:
- назва інструменту та версія: Claude (модель Sonnet 4.6, план Free);
- мета використання: допомога у формуванні структури звіту, генерації ідей та покращення формулювань відповідно до вимог;
- внесок автора: отримані результати були перевірені, проаналізовані та відредаговані, після чого адаптовані відповідно завдання.


1. Запит (prompt) для опису Scope of Initial Release:
Допоможи описати розділ Scope of Initial Release для IoT-системи автоматичного годування домашніх тварин FeedMate. Backend на Node.js + Express + MSSQL, Web-клієнт на React, Mobile-клієнт та IoT-пристрій на ESP32 (C++). Опиши основні функції першого релізу: планування годувань, дистанційна подача корму, сповіщення про низький рівень корму, перегляд історії, профілі тварин.
Отримана відповідь:
Claude запропонував структурований опис Initial Release, де центральним елементом є backend-сервер з JWT-автентифікацією, який зберігає дані про користувачів, тварин, пристрої та історію годувань. Також було описано Web-клієнт для основного керування, Mobile-клієнт з push-сповіщеннями та IoT-модуль на ESP32, який отримує розклад, виконує годування та надсилає підтвердження на сервер. Матеріали були адаптовані та використані у підрозділі 3.1 звіту.
2. Запит (prompt) для опису Scope of Subsequent Releases з інтеграцією ШІ:
Опиши перспективи розвитку системи FeedMate у наступних релізах з акцентом на інтеграцію штучного інтелекту. Включи три аспекти: застосування ШІ для покращення системи, методи збирання даних для навчання моделей, підходи до використання готових API та fine-tuning власних моделей.
Отримана відповідь:
Claude сформував три підрозділи: застосування ШІ (автоматичне коригування порцій, виявлення аномалій апетиту, прогнозування закінчення корму, аналіз фото тварини для Body Condition Score); збирання даних (історія годувань, динаміка рівня корму, параметри тварин, дані про пристрої); підходи до навчання моделей — від використання готових API (OpenAI GPT-4o, Anthropic Claude) на початковому етапі до fine-tuning відкритих моделей (Llama 3, Mistral) та edge AI на IoT-пристрої у довгостроковій перспективі. Матеріали були використані у підрозділі 3.2 звіту.
3. Запит (prompt) для формулювання Limitations and Exclusions:
Сформулюй розділ Limitations and Exclusions для першого релізу системи FeedMate. Поясни, чому навмисно виключені такі функції: вбудована камера в IoT-пристрої, повноцінний офлайн-режим, підтримка кількох тварин на одному пристрої, інтеграція зі сторонніми сервісами здоров'я, голосове керування, сімейний багатокористувацький доступ та платіжна система.
Отримана відповідь:
Claude сформував обґрунтування для кожного обмеження: відсутність камери пояснюється ускладненням апаратної частини та питаннями приватності; відсутність офлайн-режиму — складністю синхронізації даних без сервера; обмежена підтримка кількох тварин — необхідністю складної бізнес-логіки розподілу порцій; голосове керування потребує додаткової сертифікації навичок; сімейний доступ та платіжний модуль залишені для наступних релізів після стабілізації ядра системи. Матеріали були адаптовані та використані у підрозділі 3.3 звіту.
